# DESeq2 Analysis (Excluding Parent-Replicate-1)

This folder contains the files necessary for DESeq2 differential expression analysis of all samples (excluding Parent-replicate-1) and the outputs (including visual plots).

### Inputs
* **`genes_plus_pseudogenes_counts_with_adhb_pdc.txt`**: The raw count matrix containing all protein-coding genes, pseudogenes, and the appended *adhB* + *pdc* counts required to run the DESeq2 analysis.
* **`ID_gene_names.csv`**: A csv file containing gene IDs and their corresponding gene symbols (extracted from the GFF file), used to add gene symbols for each gene ID in the final DESeq2 output.

### Script
* **`SCRIPT_for_doing_DESeq2_wo_Pr1.R`**: The main R script that does DESeq2 differential expression analysis of all samples excluding Parent-replicate-1. 
### Outputs
* **`DESeq_results_wo_Pr1_ss.xlsx`**: The xlsx file containing the differential expression analysis stats. Please remember the script outputs csv file (`DESeq_results_wo_Pr1_ss.csv`) instead of this xlsx file but for quick review and quick downstream analysis, some filters were applied to it to create 6 specific sheets ("All_genes", "sig_genes", "upregulated", "downregulated", "abslogfc_greater_than_log2" and "abslogfc_greater_than_log3") which are compiled into this xlsx file. The sheets in this xlsx file contain the stats of:  
  1. "All_genes"=====> All genes (analyzed by DESeq2)
  2. "sig_genes"=====>Significant genes only ($p_\text{adj}<0.05$)
  3. "upregulated"=====>Upregulated genes ($\log_2\text{FC} > 0$ and $p_\text{adj}<0.05$)
  4. "downregulated"=====>Downregulated genes ($\log_2\text{FC} < 0$ and $p_\text{adj}<0.05$)
  5. "abslogfc_greater_than_log2"=====>Significant genes satisfying threshold $|\log_2\text{FC}| > \log_22$
  6. "abslogfc_greater_than_log3"=====>Significant genes satisfying threshold $|\log_2\text{FC}| > \log_23$

* **`n_counts_wo_Pr1.txt`**: Contains the DESeq2-normalized counts for each analyzed gene across all samples excluding Parent-replicate-1.

* **`Plots/`**: A subdirectory containing the exploratory plots generated by the script, including the Volcano Plot, PCA plot, and sample-to-sample distance heatmap.
