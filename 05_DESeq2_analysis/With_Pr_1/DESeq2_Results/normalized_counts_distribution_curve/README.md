If you see the plot, the normalized counts distribution curve for Pr_1 is significantly different from those of the other five replicates. First, the curve is almost flat at lower count values and second, it forms an unnaturally steep peak exceeding 1.0 on the Y-axis between 1,000 and 10,000 counts while in contrast, the remaining replicates show a distinct peak at lower count values and broad, smooth curves with peak densities staying well below 0.6 (~0.4–0.5). This indicates that Pr_1 has virtually no genes with low expression levels and an exceptionally high concentration of genes in the mid-to-high expression range, a profile uncharacteristic of an uncompromised biological sample. This strongly suggests that Pr_1 might had suffered RNA degradation prior to sequencing which resulted in such distorted count profile.
