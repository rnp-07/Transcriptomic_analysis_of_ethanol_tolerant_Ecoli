# Gene Set Enrichment Analysis (GSEA)

This directory contains the script, inputs, and results for the Gene Set Enrichment Analysis (GSEA). The analysis was performed using both the Gene Ontology (GO) (evaluating all three categories separately: CC, BP, and MF) and KEGG databases.

### Inputs
* **`genes_plus_pseudogenes_counts_with_adhb_pdc.txt`**: The raw count matrix required to run the DESeq2 analysis (excluding Parent-replicate-1). The resulting log2 fold-changes from this step are extracted and used to rank the genes for GSEA.
* **`ID_gene_names.csv`**: A mapping file used to convert DESeq2 Gene IDs into their corresponding Gene Symbols, which is necessary for the `clusterProfiler` GSEA algorithms.

### Script
* **`Script_for_GSEA_analysis.R`**: The complete R script that performs the prerequisite DESeq2 analysis, cleans and ranks the gene list, maps identifiers to Entrez IDs using `org.EcK12.eg.db`, runs the `clusterProfiler` GSEA functions, and generates the resulting CSVs and enrichment plots.

### Outputs & Data Files
* **`Results_and_plots/`**: This subfolder contains the following output files generated by the script mentioned above:
  * **i) `GSEA_GO_CC_padj0.05.csv`**: The tabular results of the GO enrichment analysis. *(Note: While the parameter `ont` inside the `gseGO()` function can be changed from `CC` to `BP` or `MF` to perform GSEA using GO-BP or GO-MF databases, only the Cellular Component [`CC`] category yielded significantly enriched gene sets at the $p_\text{adj} < 0.05$ threshold).*
  * **ii) `GSEA_KEGG_padj0.05.csv`**: The tabular results of the KEGG pathway enrichment analysis ($p_\text{adj} < 0.05$).
  * **iii) `.png` files**: This subfolder also contains the standard enrichment plots (generated via `gseaplot2`) visualizing the running enrichment score for the significantly enriched pathways:
    * **GO-CC:** 1 enrichment plot (Pore Complex).
    * **KEGG:** 2 enrichment plots (Flagellar Assembly and Phosphonate & Phosphinate Metabolism).
